Global templates
Global templates

        

            
A global template is a saved bundle of model
                settings. You create one from the model editor ("save as template") and apply it to a
                model or profile from the editor's "apply from" list. EDIT opens the settings bundle;
                DELETE removes the template only — models already created from it keep their own settings.
